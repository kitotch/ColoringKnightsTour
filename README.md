# Coloring Knight's Tour
Coloring Knight's Tour は Knight's Tour を用いたパズルボードゲームです。  
# ルール
- 8x8のチェス盤を用いる。
- 色は4色とする。
- next (FIFO)の色を3つ、一様ランダムに決める。
- Knight (以下、単に「駒」と書く)の位置を一様ランダムに決める。
  その位置に駒を置いて、そのマスの色を一様ランダムに選びスタートする。
- 以下、駒の移動可能なマスが無くなるまで繰り返す。
- プレイヤーは駒を動かせる位置に動かす。
  - 動かせる位置の候補は駒の現在地に(±1, ±2), (±2, ±1)のいずれかのベクトルを足した位置のうち色がついていないマスである。
- 移動後のマスにnextの最初にある色を取り出しその色を付け、nextに色を1つ、一様ランダムに追加する。
- 盤の色を Rook が他の色のマスの上を通過せずに移動可能な同じ色のマスの連結成分のサイズが4以上の場合、それらのマスの色は消される。
  - 色が消えた結果、他の色が消える条件を満たす場合、連鎖としてそれらのマスの色も消す。
  - このとき、スコアの増分を連鎖回数を0から数えて、連鎖回数ごとに$\text{消した色の数} \times 2^{\text{連鎖回数}}$とする。
